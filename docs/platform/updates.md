# Changelog

Changelog summarizes code changes and their effects on your product. Use it to understand the product impact of development work without reading every commit. Open it under **Product** to investigate what changed and how a capability evolved.

## What you can do

Browse changes, narrow the view using the available search and filters, and open an entry for its details and evidence. Use [Live Docs](/live-docs) for the current description of a capability and Changelog for its change history.

## Interpret a change

Check the associated pull requests or commits and the period covered. Code-change evidence can include merged work, unfinished work, or a mixture. An entry is not a release announcement and does not by itself confirm deployment or customer availability.

For a project-specific assessment, review [Projects](/projects). For a broader briefing across code and other sources, use [reports](/reports) or [Ask Weaver](/ask-devplan).

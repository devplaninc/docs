# Bitbucket

Connect Bitbucket to turn repository code and changes into [Live Docs](/live-docs) and product context. Your team can investigate existing behavior and plan changes with the implementation in view.

## Prerequisites

A Devplan workspace Admin connects the integration. Use a Bitbucket account with access to the intended workspace and confirm that the workspace has the Devplan app access needed to discover its repositories.

## Connect

Open **Integrations → Bitbucket**, select **Connect Bitbucket**, and authorize the intended account. Return to Devplan and review the connected workspaces and repository list.

## Manage repositories

Review each repository’s **Analyze** selection, use **View analysis** to inspect its result, and **Rescan** to request another analysis. **Refresh** reloads access after permission changes. If several Bitbucket workspaces are connected, you can disconnect an individual workspace from the **Connected workspaces** list.

## Troubleshooting

If repositories are missing, confirm the Bitbucket workspace, app installation, and account access. If product knowledge is missing, inspect repository selection and processing status.

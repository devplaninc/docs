# Linear

Connect Linear to relate issue activity to customer needs, product behavior, and planned work. Weaver can use that context in project investigations, while exports let you carry a plan into the team’s issue workflow.

## Connect

As a workspace Admin, open **Integrations → Linear**, select **Connect Linear**, and authorize the intended Linear workspace. On return, check the connected organization and the **Linear teams** list. The list shows teams available for export; it is not a set of ingestion toggles. Use **Refresh** if the expected teams have not appeared.

Synced team and issue context can inform signals and project assessments. If expected issues are missing, check the connected account and its access in Linear.

## Export (one-way)

When Linear export is available for your project, use it to export the planning content. Review the destination and content before exporting.

Supported exports map a Devplan project to a Linear project, with stories and tasks represented as issues and sub-issues. Do not assume edits in Linear automatically update the original Devplan planning documents. Issue ingestion for delivery analysis is a separate capability.

## Troubleshooting

For missing context, confirm the Linear workspace, authorization, and synchronization status. For export problems, check destination permissions and the required project information.

# GitHub

Connect GitHub so Devplan can explain how your product works and what changed in the code. Repository analysis builds [Live Docs](/live-docs) and change summaries that help product and engineering teams discuss behavior with shared context.

## Connect

As a workspace Admin, open **Integrations → GitHub** and select **Connect with GitHub App**. Choose the intended GitHub account or organization and grant repository access. Devplan also offers a personal GitHub authorization option; use the GitHub App when you need to manage an installation’s repository access.

Organization policies may require an administrator to approve installation or repository access. If approval is pending, complete that step in GitHub before expecting repositories to appear.

## Manage repositories

Back in Devplan, review the repository list and its **Analyze** selections. These control which accessible repositories Devplan analyzes. Use **View analysis** to inspect the result and **Rescan** when you need a new analysis. **Refresh** reloads repository access; use it after changing the GitHub App’s repository permissions.

Initial analysis runs in the background. Check the repository's status before assuming its product knowledge is ready. A rescan is useful after significant changes; availability may depend on your account's limits.

## Troubleshooting

For a missing repository, check app access and any pending organization approval. For missing product context, confirm that the repository is selected for analysis and inspect its processing status.
